⭐ Recommended: Set Static IP (Easiest!)
Guarantees your phone always gets the same IP

iPhone:
Settings → Wi-Fi → Tap ⓘ next to hotspot → Configure IP → Manual
IP Address: 192.168.2.2 | Subnet: 255.255.255.0 | Router: 192.168.2.1

Android:
Settings → Wi-Fi → Tap network → Advanced → IP Settings → Static
IP Address: 192.168.2.2 | Gateway: 192.168.2.1

Or Find Current IP (Dynamic):

iPhone:
Settings → Wi-Fi → Tap ⓘ next to hotspot → See "IP Address"

Android:
Settings → Network → Wi-Fi → Tap network → Advanced → IP Address

Or on your Mac (Terminal):
arp -a
Look for IPs like 192.168.2.2 or 192.168.2.3

⚠️ Important:
• Your Mac (hotspot) is: 192.168.2.1
• Your phone should be: 192.168.2.2 (or .3, .4, etc.)
• Don't filter for 192.168.2.1 (that's your Mac!)
